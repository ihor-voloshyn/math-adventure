# A05 — Math task

## Цель

Проверить получение математического задания через Adaptive → Generator → Validation → Math Engine.

## Предусловия

- Установлен текущий Android APK Math Adventure.
- Тест выполняется на реальном Android-устройстве или эмуляторе.
- Если тест требует предыдущего состояния, оно должно быть получено в ходе A01–A20.

## Шаги

1. Во время боя начать математическое действие
2. открыть задание.

## Ожидаемый результат

Появляется валидное математическое задание; задача соответствует текущему игровому контексту; нет ошибки/пустого задания.

## Фактический результат

Заполняется во время ручного тестирования.

**Статус:** ⬜ NOT RUN / 🟢 PASS / 🔴 FAIL / 🟡 BLOCKED
