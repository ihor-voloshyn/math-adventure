# A01 — First launch

## Цель

Проверить первый запуск приложения и инициализацию локального состояния.

## Предусловия

- Установлен текущий Android APK Math Adventure.
- Тест выполняется на реальном Android-устройстве или эмуляторе.
- Если тест требует предыдущего состояния, оно должно быть получено в ходе A01–A20.

## Шаги

1. Удалить приложение, установить APK
2. запустить. Проверить стартовый экран
3. отсутствие ошибок.

## Ожидаемый результат

Приложение запускается на Home; локальное состояние создаётся корректно; критических ошибок/крашей нет.

**Статус:** ⬜ NOT RUN / 🟢 PASS / 🔴 FAIL / 🟡 BLOCKED
