# Screenshot inbox

Upload screenshots here when you need me to inspect something during manual Android testing.

## How to use
1. Open this folder in GitHub.
2. Choose **Add file → Upload files**.
3. Upload the screenshot(s) into this `inbox` folder.
4. Commit directly to the current branch.
5. Tell me the uploaded filename.

I will inspect the uploaded evidence and tell you what I see and which test case it relates to.

Do not upload passwords, tokens, personal documents, or other sensitive information.
