## Important limitation

This is not a raw platform-generated ChatGPT transcript. The GitHub integration does not expose the complete chat log as a downloadable conversation file. The export therefore contains the conversation/project context available in this session and explicitly marks reconstructed sections.

For an exact raw transcript, use ChatGPT's native conversation export/download feature and place the resulting file here.
