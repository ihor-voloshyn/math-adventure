# Math Adventure Documentation

## Authority and status
`01_PRODUCT_REQUIREMENTS.md` is the highest product-level authority. Specific system documents refine it. Architecture decisions are recorded separately under `architecture/decisions/`.

Current approved baseline: documents 01–09, covering product requirements, game/world/gameplay design, mathematics curriculum, Math Engine, Task Generator, Mastery System, and Adaptive Engine.

Documents 10–21 remain to be completed as the project moves toward implementation.

## System boundaries
- Math Engine = mathematical truth and learner mathematical state.
- Mastery System = mastery state evaluation/update.
- Adaptive Engine = next-step decision.
- Task Generator = concrete task generation.
- Game Engine = gameplay execution.

Changes to approved documents go through review and must not silently contradict higher-authority documents.
